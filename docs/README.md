#  在线学习平台系统

前后端分离式在线学习平台，集成课程管理、视频学习、笔记收藏、评论互动与 AI 智能答疑功能，打造一站式学习体验。

##  核心功能
- 用户权限管理：基于 JWT 实现登录认证与权限控制
- 课程体系：课程浏览、章节视频播放、学习进度跟踪
- 学习互动：笔记收藏、课程评论、学习资料下载
- AI 答疑：接入通义千问，支持 SSE 流式对话与多轮上下文记忆

##  技术栈
**前端**：Vue3 + Vite + Element Plus + Axios  
**后端**：Spring Boot + Java + MyBatis + MySQL  
**AI 集成**：阿里云 DashScope 大模型 SDK
